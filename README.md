# Studi_Kasus_4_Putrika-Juliya-Sari

nama: Putrika juliya Sari

nim: 057

Program ini digunakan untuk menyimpan dan mengelola data buku. terdiri dari data di dalam Dictionary, pilihan menu, dan perubahan data. pilihan menu terdiri dari 5 nomor, yaitu: menampilkan beberapa data, mengupdate data penulis, menghapus data penerbit, dan keluar menu. pada pilihan 4, diperlukan input untuk mengubah data.
menu akan terus berulang sampai pengguna memilih menu 'keluar'.
